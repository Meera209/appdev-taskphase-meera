# Reading Notes: CSS Box Model
**Article:** [Introduction to the CSS Box Model — MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_box_model/Introduction_to_the_CSS_box_model)

- Every HTML element is treated as a box made up of content, padding, border, and margin.
- Padding creates space inside an element, while margin creates space outside it.
- The border surrounds the content and padding.
- The `box-sizing: border-box` property makes an element's specified width include its padding and border.
- Understanding the box model helps me control spacing and create cleaner layouts in my portfolio.
